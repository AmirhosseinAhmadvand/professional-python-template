# Contributing to Professional Python Template

Thank you for your interest in contributing!

## How to Contribute
1. Fork the repository.
2. Create a new branch (`git checkout -b feature/AmazingFeature`).
3. Make your changes and ensure tests pass (`pytest`).
4. Ensure code is formatted (`ruff format .`).
5. Commit your changes (`git commit -m 'Add some AmazingFeature'`).
6. Push to the branch (`git push origin feature/AmazingFeature`).
7. Open a Pull Request.

## Code Standards
- All code must pass `ruff` linting and `mypy` type checking.
- New features must include corresponding tests in the `tests/` directory.
